# miniCompiler

# features:
1. Arithmatic operations(int and Floating)
2. Conditional statements(IF else Condition)
3. Loop(for,while)
4. Boolean Expressions

simple code generated using flex and bison. a syntax table and  (Abstract Syntax Tree) approach.

# How to run.
1. Install Flex and Bison in PC.
2. Set the Environment variable
    (C:\GnuWin32\bin)   copy the syntax to the Environment variable path for both system and users.
3. Run the Command in Command promt from the project folder location.
4. Copy the Command Promt (Readme file) in the project.
5. Run and Execute the program.
